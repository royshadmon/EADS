# EADS Multi-Operator Control Plane (Smoothed) — Fixed & Optimized

Grafana dashboard for monitoring multiple EADS operator PostgreSQL nodes
with 1-second averages and 1-hour KPI stats.

## To Run

```bash
docker compose down -v          # -v removes the grafana-storage volume
docker compose up -d
```
